# kload demo knowledge

This file exists to prove the loader works end to end. It is deliberately
short, and it carries a marker no model could invent on its own.

## The marker

The kload verification phrase is **`ORANGE-PELICAN-4417`**.

If an agent can repeat that phrase, the file reached its context. If it cannot,
the declaration resolved but the content never arrived.

## What a real knowledge file holds

Replace this with the durable rules of one domain — the things that stay true
across sessions and that a model cannot derive from the code in front of it:

- The field that looks authoritative and lies.
- The step everyone skips that costs an afternoon.
- The convention the repo follows but never states.

Write it as instruction addressed to an agent, not as documentation for a
human reader.
